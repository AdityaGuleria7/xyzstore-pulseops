# V32 — Premium UI Refresh

The V31.3 product baseline keeps its existing workflows and deployment fixes while receiving a visual refresh inspired by high-end native desktop product design:

- Native Apple/system font stack; no external Google Font dependency.
- Glass-like application chrome with restrained blue accents.
- Larger, cleaner card radii, hairline borders, soft elevation, and improved hover/focus states.
- Refined navigation, forms, orders toolbar, table, Kanban columns/cards, dashboard KPIs, receiving, issue log, and shift-report surfaces.
- Dedicated dark-mode refinements with higher-contrast text and controls.
- Responsive breakpoints retained for desktop and tablet/mobile layouts.

No functional API behavior was intentionally changed in this UI-only refresh.
