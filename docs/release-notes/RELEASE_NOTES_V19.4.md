# PulseOps V19.4 — Kanban Navigation Cleanup

- Removed the separate left-side pipeline navigation rail from Orders & Priority.
- The Kanban board now uses the full available width.
- Each fulfillment stage remains independently vertically scrollable.
- Each order retains its compact vertical stage progress slider.
- Clicking an order's stage slider can still jump to the corresponding stage column.
- The horizontal stage board remains available for navigating across all six stages.


V19.4 Card sizing polish
- Worker Mode main work card no longer stretches to match the pick queue height.
- Pick queue gets its own capped scroll viewport.
- Preserves responsive behavior and keeps the primary work card compact and readable.
