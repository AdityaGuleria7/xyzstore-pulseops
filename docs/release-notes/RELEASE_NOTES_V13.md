# PulseOps V13

- Added global live clock context and richer timestamps across orders, stock, receiving, staging and worker logs.
- Dashboard now includes an interactive six-stage fulfillment pipeline, expanded KPI set, global order/sales map, market totals, worker presence/roles, and a compact expandable deadline watchlist.
- Command Center now shows worker-wise saved logs, per-worker metrics, presence/role, and last activity.
- Kanban stages now map to six real fulfillment stages, with live timers, progress slider visuals, and correct label/picking actions.
- Stock search control aligned with the shared UI, includes a clear action, and displays Last Updated timestamps.
- Receiving and pickup records expose operational timestamps for follow-up and auditability.
