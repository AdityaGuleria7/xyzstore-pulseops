# PulseOps V19.3 — Individual Kanban Stage Scrolling

- Each fulfillment pipeline stage now has its own vertically scrollable order list.
- Scrolling inside Received, Processing, Picking, Packing, Staging, or Shipped does not move the other stages.
- Stage headers remain visible while that column scrolls.
- Existing per-order vertical stage slider remains on every card.
- Existing stage rail still jumps to the selected pipeline column.
- Responsive layout keeps horizontal stage navigation while preserving independent vertical scrolling.


## V19.4 presentation adjustment
- Removed the separate left-side Kanban pipeline rail from the Orders screen.
- Retained the individual per-order vertical stage sliders and independently scrollable stage columns.
- The Kanban board now uses the full available width for order cards.
