# PulseOps V21 — Night Mode Readability

## Fixed
- Improved contrast for slate text, headings, labels, controls and table metadata in dark mode.
- Added dark equivalents for common light surfaces and borders used across operational tabs.
- Improved readability of coloured status/priority/category indicators in night mode.
- Fixed dark-mode form fields, placeholders and focus states.
- Improved map popup and attribution contrast in night mode.
- Improved scrollbars and Kanban slider visibility in dark mode.
- Preserved the V20 header polish and the V19/V19.3 operational UI changes.

## Design goal
Night mode now maintains the same information hierarchy as light mode without relying on low-contrast slate text on dark surfaces.
